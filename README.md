# Student Performance Prediction Using Machine Learning

## Project Summary
A beginner-level machine learning project that estimates student final marks from study hours, attendance, previous marks, and assignment score.

## Technologies Used
- Python
- Google Colab
- Pandas and NumPy
- Scikit-learn — Linear Regression
- Matplotlib
- Gradio

## Features
- Student dataset creation and processing
- Model training and prediction
- Evaluation using MAE and R²
- Graphs comparing student inputs and predicted marks
- Browser-based prediction interface

## How to Run
1. Open the notebook in Google Colab.
2. Run the cells in order.
3. Run the Gradio interface cell.
4. Open the generated app link to test predictions.

## Dataset Notice
This prototype uses 15 synthetic sample records. Its predictions are for educational demonstration only and are not validated for real student outcomes.
